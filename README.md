# UIDemo

스마트폰 홈 화면처럼 앱 아이콘에서 앱 화면이 펼쳐지고, 홈 바를 위로 쓸어 올리면 닫히는 UI 연출 데모입니다.

| 항목 | 내용 |
| --- | --- |
| 엔진 | Unity 2022.3.62f1 |
| 언어 | C#, DOTween |
| 코드 위치 | `Assets/Scripts` |

## 구현 내용

- **앱 열기·닫기** (`Controller`): 앱 아이콘의 화면 위치를 캔버스 기준 0~1 좌표로 바꿔 패널의 피벗으로 쓰고, 그 피벗을 기준으로 `DOScale`을 실행합니다. 그래서 패널이 어느 아이콘에서든 그 아이콘 자리에서 커지며 열립니다. 닫을 때는 피벗을 중앙으로 되돌린 뒤 작아지게 합니다. 열기는 `OutCubic`, 닫기는 `InCubic` 이징을 썼습니다.
- **홈 바 제스처** (`HomeButton`): 화면 아래쪽(150px 이내)에서 누르기 시작해 200px 이상 위로 끌면 패널을 닫습니다. 짧게 스친 입력은 무시하도록 누른 지 0.1초가 지난 뒤부터 드래그를 인식합니다.
- **커서 트레일** (`CursorTrail`): 마우스 위치를 월드 좌표로 바꿔 트레일 오브젝트가 `Lerp`로 따라오게 했습니다.
- **효과 토글** (`AppPanel`): 트레일, 파티클, 애니메이션 효과를 토글로 켜고 끌 수 있습니다.
